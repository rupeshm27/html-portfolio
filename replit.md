# SportsLogin

## Overview
A static HTML/CSS website featuring a login page and various sample HTML pages. This is a simple frontend-only project with no backend or build system.

## Project Structure
- `index.html` - Main login page
- `solution.html` - Solution example page
- `public/` - Additional HTML pages (about, contact, birthday-invite, movie-ranking)
- `assets/images/` - Image assets

## Development
- **Server**: Uses `serve` to host static files on port 5000
- **Command**: `npx serve -l 5000`
